# CBDC Transaction Simulation Framework

A scalable simulation framework for modeling the economic behavior of users in a Central Bank Digital Currency (CBDC) system.

## Overview

This project provides a simulation framework for CBDC research. It is designed to model the lifecycle of transactions within a large-scale, simulated user base with diverse economic profiles. The framework allows researchers to study payment network topology, user behavior patterns, and the potential impact of different economic scenarios.

The system is a **simulation tool** and does **not** implement a live DLT, a real-world consensus mechanism, or a production-ready compliance system. It is intended for research and modeling purposes.

## Core Features

- **User Simulation**: Generate large populations of simulated users (100,000+) with configurable economic profiles (e.g., income, spending habits).
- **Transaction Generation**: Simulate a variety of transaction types (e.g., payments, transfers, deposits) based on user profiles and economic models.
- **Agent-Based Modeling**: Model user behavior with an agent-based approach, allowing for complex interactions and emergent network effects.
- **Data Export**: Export comprehensive analytics data, including transaction logs and user profiles, for further analysis in external tools.
- **Scalable Simulation**: The framework is designed to be memory-efficient and can simulate large-scale scenarios on standard hardware.

## Architecture

The system is designed as a modular simulation framework:

```
┌─────────────────────────────────────────────────────────────┐
│                  CBDC Simulation Framework                  │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌─────────────────┐  ┌──────────────┐ │
│  │   Simulation    │  │   Transaction   │  │   Analytics  │ │
│  │   Engine        │  │   Generator     │  │   Exporter   │ │
│  └─────────────────┘  └─────────────────┘  └──────────────┘ │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌─────────────────┐  ┌──────────────┐ │
│  │   User Profile  │  │   Economic      │  │ Configuration│ │
│  │   Manager       │  │   Model         │  │   (JSON)     │ │
│  └─────────────────┘  └─────────────────┘  └──────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

- **Simulation Engine**: Orchestrates the simulation, managing time and events.
- **Transaction Generator**: Creates transactions based on user profiles and economic models.
- **Analytics Exporter**: Collects and exports simulation data.
- **User Profile Manager**: Manages the creation and lifecycle of simulated users.
- **Economic Model**: Defines the macroeconomic conditions of the simulation.

## Current Status & Known Issues

This is a research-level simulation tool. The following limitations are important to understand:

- **No Real Consensus**: The simulation does not implement a distributed consensus mechanism. Transactions are processed locally.
- **Simplified Compliance**: The compliance checks are placeholders and **all transactions are automatically approved**.
- **Hardcoded Analytics**: Some analytics calculations return hardcoded values.
- **Economic Shock Scenario**: The "economic shock" scenario is not fully implemented and does not currently model a differential response compared to the baseline scenario.
- **Transaction Amount Bugs**: There are known issues with the calculation of transaction amounts, particularly for high-income entities, which can result in unrealistic values.

## Research Applications

This simulation framework can be used for research in areas such as:

- **Economic Modeling**: Study how different economic conditions affect user behavior and transaction patterns.
- **Network Analysis**: Analyze the topology of payment networks that emerge from user interactions.
- **Behavioral Economics**: Model how different user profiles adopt and use a CBDC.
- **Scalability Research**: Test the performance of transaction processing systems with large, realistic datasets generated by the simulation.

## Getting Started

### Prerequisites

- Node.js 18+
- TypeScript 5+
- Jest for testing

### Installation

```bash
# Navigate to the demo directory
cd demos/cbdc-research-pilot

# Install dependencies
npm install
```

### Running the Demo

```bash
# Run the basic demo
npm run demo

# Run with 100,000 users
npm run demo:large
```
